# MASTER PROMPT — GOOGLE AI STUDIO

Quero desenvolver este projeto em etapas, mantendo o código simples, modular e compreensível para um usuário intermediário em informática.

## Tecnologia obrigatória

- Python
- Streamlit
- SQLite
- Pandas
- Plotly
- GitHub para versionamento

## Restrição importante

Não faça a aplicação depender obrigatoriamente da API Gemini para funcionar.

O núcleo financeiro deve ser determinístico em Python.

A IA deve ser um módulo opcional para:
- explicar resultados;
- resumir riscos;
- gerar texto do relatório;
- responder perguntas sobre a carteira.

## Objetivo

Criar um sistema de planejamento financeiro brasileiro com:

1. perfil do usuário;
2. patrimônio;
3. aportes;
4. renda desejada;
5. carteira atual;
6. cenário macroeconômico;
7. renda fixa;
8. FIIs;
9. ETFs;
10. ações;
11. alocação estratégica;
12. projeção patrimonial;
13. taxa de retirada;
14. inflação;
15. tributação;
16. risco;
17. concentração;
18. rebalanceamento;
19. relatório.

## Regra de desenvolvimento

Não reescreva o projeto inteiro a cada alteração.

Antes de alterar:
- identifique o arquivo;
- explique a mudança;
- preserve as funções existentes;
- forneça somente os arquivos alterados ou o patch necessário.

## Regra financeira

Cálculos de:
- juros compostos;
- inflação;
- retorno real;
- impostos;
- taxa de retirada;
- alocação;
- rebalanceamento;

devem ser feitos por funções Python testáveis.

Não use o modelo de linguagem para "chutar" valores financeiros.

## Critérios de qualidade

- código simples;
- funções pequenas;
- nomes em português quando fizer sentido;
- comentários nas partes financeiras;
- tratamento de erros;
- validação de entradas;
- testes unitários;
- nenhum dado inventado;
- datas de referência sempre visíveis;
- fontes registradas para dados externos.
